# Game reference (MapleStory, GMS)

What the calculator models about the game, where each number lives in the code, and how far each one can be trusted. Read before touching game data, adding a symbol (Grand Sacred), or answering a player's "is this number right?". The data itself stays in `src/lib/symbols.json`, `src/lib/game.ts` and `src/lib/ratioData.ts`, which the code reads; this doc explains it, records provenance, and quotes numbers only inside the marked tables, which `src/test/docs.test.ts` checks against the data both ways.

## 0. Scope and trust (read first)

- **GMS only.** Every number is Global MapleStory. Brian confirmed on 2026-09-22 that Heroic (Reboot) and Interactive worlds use the same symbol numbers; the one difference the site shows is that the Catalyst is Interactive-only ("Regular Server Only" in the Tools copy).
- **Other regions were researched, not confirmed** (§5): the same game everywhere, with rates arriving on each region's own patch date and names of their own. Today the site shows GMS numbers only, and the page must never imply they are another region's. Brian decided on 2026-09-22 that 2.0 shows each server's own numbers, each with its status (`docs/REGIONS.md`); until then this rule stands.
- **Trust comes from §7.** The site was built from the Credits resources (MapleStory Fandom wiki, StrategyWiki, Orange Mushroom's blog) with no record of which number came from where. §7 now logs every check. A number is **confirmed** once a row says Brian saw it in game, **sourced** once a dated source agrees, and otherwise **unverified**. As of 2026-09-22 the daily and weekly rates, the reset times, the Catalyst, the per-level stat gains and the Grand Sacred basics are confirmed; the EXP and meso tables are sourced, with one EXP row confirmed.

## 1. Symbols

Fourteen symbols in three families (`type`). Arcane Symbols (Arcane River regions) level to 20 and give Arcane Power; Sacred Symbols (Grandis regions) level to 11 and give Sacred Power; Grand Sacred Symbols (Western Grandis, `grand`, §4) level to 11 on the Sacred table and give Sacred Power too, but no main stat. The current UI (`src/components/`) lists the first two families only; the `/next` redesign (`src/next/`, ARCHITECTURE §2) adds a Grand tab (REGIONS D-18). Ids are permanent (saved progress is keyed on them, AGENTS gotcha 2); JSON order is display order only.

**Daily counts are post-v.271** (see §7): GMS doubled them on 2026-09-09, the site was updated to match on 2026-09-22 (KI-014), and Brian confirmed every one in game the same day. Vanishing Journey and Chu Chu show their base rate, which the extra quest doubles to 40; the other four arcane regions give 40 outright.

"Mesos to max" is the sum of the symbol's `mesosRequired`, level 1 to max. Every meso table follows one formula per family, which reproduces all 194 per-level costs in `symbols.json` exactly, the Grand Sacred ones included, whose totals Brian saw in game (checked 2026-09-22, recomputed 2026-09-23). For the upgrade from level L: arcane costs 10,000 × ⌊(L² + 11) × (k + 0.1L)⌋ with k = 8, 10, 12, 14, 16, 18 for ids 1–6; sacred costs 100,000 × ⌊(9L² + 20L) × (k − 0.6L)⌋ with k = 13.2, 15, 16.8, 18.6, 20.4, 22.2 for ids 7–12, and 39.8 (Tallahart) or 48.8 (Geardock). Compute it in integer tenths (or add a tiny epsilon before the floor): plain floating point gets 5 of the original 174 wrong, because 15 × 8.2 comes out as 122.99…. So a new symbol or a flat cost change (KMS's 30 % arcane cut, §5) can be checked by computing it rather than by typing a table. The per-level EXP tables are shared by every symbol of a type (`arcaneExpRequired`, `sacredExpRequired` in `symbols.json`, loaded as each symbol's `symbolsRequired`); the per-level meso tables are per symbol. The Handbook page renders all of them.

How the calculator uses them (the code-facing version is AGENTS.md's domain cheat sheet):

- **Daily rate** = daily symbols × extra multiplier when the extra quest is on, 0 when the daily is off. Only Vanishing Journey and Chu Chu have an extra quest; only arcane symbols have a weekly. The sacred extra multiplier (1.5) has no counterpart in the game, since no sacred region has an extra quest, so it never applies; Grand Sacred has none at all (`null`, and `getDailySymbols` uses ×1).
- **Days to go** count from tomorrow (today's quests are assumed done) and credit the weekly on each counted Thursday. The days are the server's game days (`gameToday` in `src/lib/regions.ts`), not the visitor's calendar; see §3.
- **Power**: arcane `level × 10 + 20`, sacred and Grand Sacred `level × 10`. The Graph adds +10 per level-up. In the game Grand Sacred power counts towards the same Sacred Power total; `usePower` and `buildDateSymbols` do too, via `inFamily(type, family)` in `src/lib/game.ts` (true for a family's own type, and for `"grand"` inside `"sacred"`), so the Sacred total sums both families even where the current UI (`src/components/`) never shows a Grand symbol itself (Brian, 2026-09-23).
- **Catalyst** (Interactive worlds only): transfers a symbol once within a world, keeping 80 % (arcane) or 60 % (sacred) of its cumulative EXP; needs level 2 or higher. No Catalyst exists for Grand Sacred (`CATALYST_RETENTION.grand` is `null`). The Tools copy states this as "-20% EXP" / "-40% EXP" (literal in `src/i18n/en/tools.ts`, not derived from `CATALYST_RETENTION`).
- **Symbol Selector**: adds a chosen number of symbols and levels up as far as they reach. It works on every Arcane and Sacred symbol and on Tallahart (the Sacred Symbol Selector, v.271), not on Geardock: `"selector": false` in `symbols.json`, read by `selectorWorksOn` in `src/lib/game.ts`.
- **Class exceptions** in the next-level panel: Demon Avenger gains HP instead of main stat (2,100 arcane / 4,200 sacred per level) and Xenon gains all stat (48 / 96); per server in `src/lib/regions.json` (`classGains`, one value per family that gives main stat; Grand Sacred gives none, so it has no entry). At level 1 a symbol gives 6,300 / 10,500 HP or 144 / 240 all stat, which is the same 21 HP or 0.48 all stat per point of the 300 / 500 level-1 main stat. So there is no separate per-symbol bonus, and the panel (which shows the gain per level-up) needs nothing more.
- **Damage ratios** (Handbook): arcane by the percentage of the map's requirement met, sacred by the difference from the requirement; values in `src/lib/ratioData.ts`. Brian chose on 2026-09-22 to follow the official Korean and Japanese guides. They are guide pages, which lag patches (M-014), so the tables are medium trust; they have not changed since launch in any source (links in `docs/data-check/gms-ratios-sacred.csv`). Every value matches both; the lowest sacred band is labelled ≤ −95 to match them (it said < −100 before). The Korean page adds that above the requirement damage dealt rises by half the difference, in percent, up to +25 %, so the positive sacred rows are points on a line rather than bands.

Two real sources of symbols the calculator ignores, because both are temporary and per-character. A player using either finishes sooner than the site says.

- **Event perks that raise the daily rate.** Recurring events (the Night Troupe festivals, seasonal passes) sell a perk with event currency that adds symbols to every regional daily — the v.271 Night Troupe's Daily Quest Reward perk gives +2 at level 1 (Junior) and +3 more at level 3 (Veteran), so +5 a day per region at maximum, for the length of the event. Not to be confused with **Champion's Renown**, a monthly Legion Champion buff that grants stats and bonus EXP for 30 minutes and no symbols at all.
- **Event coupons in bulk.** Symbol Selector coupons arrive by the hundred from events, and Hyper Burning hands out pre-levelled symbols. These are a lump of symbols, not a rate.

## 3. Resets and time

- The code assumes the daily reset gives one day's symbols per calendar day and the weekly quest pays on Thursday.
- GMS resets dailies at 00:00 UTC (Brian, 2026-09-22: 8 pm EDT). The calculator counts days on that clock, whatever the visitor's time zone (KI-013, resolved on `v2`): a New York player on Wednesday evening after 8 pm EDT is already on game Thursday. Each server's offset is in `src/lib/regions.json`.
- **The weekly resets Thursday 00:00 UTC in GMS**, confirmed in game by Brian on 2026-09-22. It used to be Monday. Every region moved it, each at 00:00 in its own time zone: KMS first on 2025-06-19 (the Assemble update, which unified all weekly content on Thursday; seen through Orange Mushroom's translation, not the KMS notice itself), then MSEA v246 on 2025-11-11, GMS v.264 on 2025-11-12, JMS ver4.38 on 2025-12-11, TMS most likely on 2025-12-03 (the beanfun notice is undated) and CMS V222 on 2026-01-07. The official lists name all six Arcane River weeklies (Erda Spectrum to Esfera Guardian); the CMS notice covers all weekly content in one line. The hour of the weekly is official for GMS (v.264: 12:00 AM UTC) and MSEA (0000hrs); for KMS, JMS, TMS and CMS only the day is, and 00:00 local is inferred from their other weekly content. Dailies reset at 00:00 local everywhere; outside GMS that rests on indirect or general statements, since no notice states it for the symbol dailies. Each server's `weeklyResetDay` in `src/lib/regions.json` holds the day (it was `WEEKLY_RESET_DAY` in `src/lib/utils.ts` before the region data layer).

## 4. Grand Sacred symbols (in the data since 2026-09-23; in the interface only at `/next` since then too)

Brian decided on 2026-09-16 that 2.0 includes them (V2_PLAN). Two exist: **Tallahart** and **Geardock**, the Western Grandis symbols (Tallahart from level 290, Geardock from 295, per v.270). GMS got Geardock on 2026-07-22 (v.270). The full sheet with sources is `docs/data-check/grand-sacred.csv`. Their +10 per level counts toward the Sacred Power total, as it does in game (Brian, 2026-09-23; `inFamily`, §2 above).

**Modelled on `v2` (2026-09-23)** as their own family, `type: "grand"` (REGIONS D-18): ids 13 (Tallahart) and 14 (Geardock) at the end of `symbols.json`, with the rules in `src/lib/game.ts` (§2 table; `null` where a rule does not exist). The store's `mode` is `SymbolType` (arcane, sacred, or grand) and can hold a Grand selection (`selectSymbol(13 | 14)`, `setMode("grand")`, `DEFAULT_SELECTION.grand` is Tallahart), but only the `/next` redesign (`src/next/`, ARCHITECTURE §2) offers a Grand tab. The current UI (`src/components/`) still has none: its seven files read the family through `useMode()` (`src/state/store.ts`), which folds a Grand selection back to Sacred there, and `Mode` (`Exclude<SymbolType, "grand">` in `src/lib/types.ts`) keeps every one of its lists filtering on `symbol.type === mode`, so no card in the current UI shows a Grand symbol even though the store can select one. Not in the data, because nothing reads them yet: the level requirement (290 / 295), the EXP / meso / drop bonuses and the boss damage bonus below. `img` names `/symbols/tallahart-symbol.webp` and `/symbols/geardock-symbol.webp`, which do not exist yet (the images are not collected); add them before an interface shows the family's icons.

Confirmed in game by Brian on 2026-09-22:

- **The spelling is Geardock** (older notes said "Geardrak").
- **Max level 11, and the same symbols-per-level table as Sacred** (29 … 1100, 4565 to max).
- **One daily quest each, 15 symbols a day**, no weekly and no extra quest.
- **No main stat.** The wiki says they give EXP, meso and drop rate instead (+50 %, +15 %, +15 % at max). Every other symbol gives main stat, and the next-level panel is built around that, so this is the finding most likely to change the 2.0 design.
- **No Catalyst** (official, v.270). **The Sacred Symbol Selector covers Tallahart, not Geardock**: Brian confirmed in game on 2026-09-22 that it works on Tallahart, as Nexon's v.271 notes say ("Added Grand Sacred Symbol: Tallahart to the list of items that can be received from Sacred Symbol Selector Coupons"; KMS 1.2.419 matches). Geardock is excluded in every region's notes. (His first answer, "no Selector", is corrected.)
- **Meso costs**: their own tables. Brian saw 16,072,800,000 for Tallahart and 20,181,300,000 for Geardock in game, exactly the totals of the wiki's per-level tables. (This doc first gave 24,181,300,000 for Geardock, an addition error, M-013.)

Official in Nexon's v.270 notes (linked in `docs/data-check/grand-sacred.csv`): **+10 Sacred Power per level** (110 at max) and EXP / meso / drop +10 / +5 / +5 % at level 1, rising to +50 / +15 / +15 % at level 11, plus +20 % damage to Baldrix (Tallahart) or Jupiter (Geardock) at level 11. From the wiki only: the per-level meso split (which the formula in §1 reproduces). **Not found yet:** the damage ratio table for their maps (entry requirements seen: 630 / 660 / 700 Authentic Force) and the symbol images.

## 5. Other regions (researched 2026-09-22, not confirmed in game)

Structurally every region is the same game: the same 6 + 6 symbols, the same symbols-per-level tables (2679 / 4565), the same max levels, force and main-stat gains, the same catalyst retention, and the same arcane damage-ratio table. Two things differ.

- **Changes arrive region by region, Korea first.** The doubled rates reached KMS on 2026-03-19, MSEA on 2026-06-03, TMS and CMS on 2026-06-24, JMS on 2026-07-02 and GMS on 2026-09-09, so every region now pays the same dailies. KMS has moved on twice since: its Arcane weekly became **one clear of 240** instead of three of 80 (1.2.416, 2026-06-18; same weekly total), and its **Arcane symbols cost 30 % less** to level (1.2.419, 2026-09-17): each cost is 0.7 × the old one, rounded down to 10,000 mesos, so all six now total 1,622,560,000 instead of 2,318,520,000 (`docs/data-check/kms-mesos-arcane.csv`, checked against Nexon's own screenshot and two community sources). Sacred and Grand Sacred costs were not cut. The same patch (1.2.419) also raised Xenon's symbol stats: arcane 144 → 198 at level 1 and 48 → 66 per level, sacred 240 → 330 and 96 → 132 (update 812). All three are likely to reach GMS in a later patch; the cost cut would change every arcane meso figure on the site, and the Xenon change the next-level tooltip.
- **Names differ, and not only by script.** MSEA is English but uses KMS-derived names (Road to Extinction, Chew Chew Island, Lacheln, Moras, Hotel Arcs, Authentic Symbol, Talahart, Geardrock). CMS calls symbols 徽章 (badges) rather than 符文. One name list per language lives in `docs/data-check/`.

Also worth knowing: Geardock arrived last in JMS (2026-08-26) and MSEA (2026-07-20), and MSEA's v252 prints Geardrock's daily as 10, which the site reads as a copy slip and shows as 15 (Brian, 2026-09-23; see below). Every region resets at 00:00 local time, weekly on Thursday. TMS's costs match GMS: Sacred and Grand Sacred digit for digit in a table updated for v282, Arcane through an independent TMS calculator (medium confidence, no official table). **CMS and JMS costs equal GMS** (checked 2026-09-23 by script, cell by cell): CMS's official guide wiki 357578 prints the Arcane, Sacred and Tallahart tables (the stale BWIKI tables predate the 2023 cut), and JMS's ver4.17 notice (2023-09-20) lists the reduced Arcane and Sacred costs; kiiten's JMS differences (Arcane from 12→13, Arcus 5→6) are its own errors. Neither has KMS's 2026 Arcane cut. CMS Geardock's costs are unpublished and inferred equal to GMS. MSEA's are inferred: v225 (2023) made the same cut as Korea, and no patch since has touched costs. For each of these, one dated in-game screenshot would settle it. The Grand dailies outside GMS, KMS and JMS rest on inference (research 2026-09-23): KMS 1.2.413 raised both Grand dailies to 15 under the Sacred heading, every server applied that raise, and JMS, the one server that got Geardock after the raise, printed 15. So TMS and CMS Geardock are taken as 15, and MSEA Talahart as 15 (v251: "the rest 10 to 15"). MSEA's own v252 text says Geardrock gives 10, but that paragraph is the v238 Talahart paragraph with the names swapped (it even keeps Talahart's quest name), so the 10 is probably a copying slip. All of this is recorded for the 2.0 decision about whether the site ever shows another region's numbers; today it shows GMS only (I18N §0).

**Grand Sacred per server, in `src/lib/regions.json` (2026-09-23).** Every server has both symbols now (JMS opened Tallahart with ver4.30 その3 on 2025-02-19 (ver4.43 on 2026-07-02 only raised its daily) and Geardock with ver4.44 on 2026-08-26), so the roster needs no override. Encoded: no daily override (MSEA's Geardrock is shown at 15 like everywhere else; its printed 10 is read as a copy slip, Brian 2026-09-23), and a `mesosGrand` status per server for the two cost tables: sourced for GMS, KMS (namu.wiki), JMS (kiiten's totals) and TMS (gamer.com.tw), inferred for MSEA (every server with a published table matches GMS), inferred for CMS (Tallahart in its official guide, Geardock not published). KMS did not cut them. Recorded here only, because a status covers one kind of number for a whole server and these differ within one: MSEA's Talahart count and the TMS and CMS Geardock counts are unpublished, yet read as the GMS 15 under those servers' `dailySymbols` status (sourced). The per-symbol status of REGIONS §3 (`{ value, status, source, since }`) would express them; until then no page shows a Grand Sacred number, so nothing is shown wrongly.

## 6. When the game changes

`pnpm check:data` (`scripts/check-game-data.mjs`) watches every number that patches have changed before, on every server. `.github/workflows/game-data.yml` runs it every Monday. It never edits the data: a patch note can describe another region, a temporary event bonus, or a change GMS has not received, so a person decides.

**Each server's expected numbers come from its own overlay**: `symbols.json` with that server's `regions.json` entry applied by id, as `createInitialSymbols(region)` builds them. The script is plain Node, so `scripts/game-data.mjs` mirrors that merge (`expectedFor`) together with the regional parsers, and `src/test/dataWatcher.test.ts` fails if the mirror and the site ever disagree.

**Sources**, listed once in the script's `SOURCES`. GMS has two that do not depend on each other, and the report says which one is ahead when they disagree:

- **The MapleStory Wiki** (maplestorywiki.net, MediaWiki API): the current numbers. It mirrors GMS within about a day of a patch. (The Fandom wiki is abandoned: its symbol pages were last edited in 2024.)
- **Nexon's GMS patch notes**: the JSON behind nexon.com's news pages (`g.nexonstatic.com/maplestory/cms/v1/news`), readable without a browser. Any update, maintenance or general notice from the past week that mentions symbols is reported line by line.
- **The cost formula** (§1): all 194 of our per-level costs are also compared with the formula (each symbol's k is in the script's `COST_K`), which catches a typo in `symbols.json` even when the wiki agrees with it.

**The other servers** (built 2026-09-23, REGIONS §7 item 9). Each has its own section in the report and in the issue:

**The Catalyst world limit per server** (`catalystRegularWorldOnly` in `regions.json`, Brian 2026-09-23: drop the tag where no Reboot-type world exists): GMS yes (not sold in Heroic/Reboot); TMS no (its Reboot world was converted in waves from 2024-11-27 and renamed 米特拉: bulletin 2025-02-19 "修正殘留的RB名稱修正為米特拉", 2026-01-22 "米特拉(舊Reboot)"; the older notice 9922 that 真實觸媒 "不在Rb世界販售" predates it); MSEA no (only Normal and Challengers worlds; no official text limits it); CMS no (普通世界 vs the seasonal 挑战者世界 only); KMS no (its Reboot worlds became the regular Eos and Helios over three 2024 patches, maplestory.nexon.com notice 144849); JMS no (its Reboot world became a 一般ワールド on 2024-10-22). The Tools tooltip shows "[… Only]" only where it is true.

**JMS class gains stay on the GMS inference** (Brian, 2026-09-23): kiiten lists Xenon +39 / +78 and Demon Avenger +1,400 / +3,500 per arcane / sacred level, against our inferred 48 / 96 and 2,100 / 4,200; kiiten is low trust and no official JMS source states them, so the site keeps the inference (status "inferred") and the watcher keeps reporting the difference only if it changes.

**Community tables report only what is new.** kiiten and BWIKI are low trust, and they already differ from our numbers (§7, 2026-09-23). Every difference they show is information, never a failure (exit 3, not 1), and the lines recorded in the script's `KNOWN_DIFFERENCES` stay quiet; a line that is new, or a recorded one that goes away, is reported. Each cost line carries both totals, so an edit at any level changes it. After reading a new difference, record it here (§5 or §7) and copy the line into `KNOWN_DIFFERENCES`. A partial read (one page unreadable) never reports recorded lines as gone.

**Checked on GMS, because it has moved before:** daily symbols per region; whether an extra quest exists and what it raises the daily to; the weekly (per clear × clears); the daily, weekly and extra quest names (a replaced quest usually means its reward changed); every per-level meso cost of all 14 symbols (the 2023 reduction, KMS's 30 % arcane cut in 2026); the per-level gains in power, main stat, Demon Avenger HP and Xenon stat (KMS raised Xenon's in 2026); and the symbol lists for Arcane, Sacred and Grand Sacred (a new region). Grand Sacred is checked like the others since it joined `symbols.json` (2026-09-23; it had waited in the script's `PENDING` list, now empty, which is where a symbol the game has and the data lacks goes next time). The weekly and the class gains are read from the GMS profile in `src/lib/regions.json`, and the weekly is compared as the game pays it (per clear × clears), so a move to KMS's single clear of 240 is caught even though the total stays the same.

**Not checked, because it has not moved in years:** the symbols-per-level tables and the max levels (since each family launched; a changed max level still shows up as a different number of cost rows), the damage ratio tables, the Catalyst retention, the daily reset hour, and the level-1 stat amounts. Selector and Catalyst eligibility is not checked either, although v.271 changed the Selector list; it matters only once 2.0 models Grand Sacred in Tools. The weekly reset day did move once (2025) but no source states it in a form a script can read; the patch-note scan also reports lines about a weekly reset day (초기화 요일, 初期化 曜日, reset day). The same goes for every other server's reset day and extra quest.

**What reaches GitHub.** The workflow writes only when something changed. It opens a `game-data` issue the first time a report is not clean (a number disagrees, a source is unreadable, a patch note from the past week mentions symbols, or a community table changed), comments only when the report differs from the last one posted, and closes the issue once everything matches again. The report starts with what was read and what is left to a person (the script's `MANUAL` list, REGIONS §0), then one `## GMS`, `## KMS` … section per server with findings; the workflow turns each into a heading and a code block, and names those servers in the issue title. Exit codes: 0 clean, 1 a number disagrees (GMS, or a regional overlay against its own rule), 2 a source is unreadable, 3 a heads-up only.

On a GMS patch that touches symbols:

1. Compare each number the patch mentions with §1 and §2 and with `symbols.json` / `ratioData.ts`.
2. Edit the data files, then this doc's tables (the docs test fails until they agree), then record the check in §7.
3. A new symbol: follow ARCHITECTURE §9 (add a symbol). New ids only, never reuse one. No `STORAGE_VERSION` bump is needed (AGENTS gotcha 2).
4. New or renamed game names also need their translated names (I18N §9).
5. Player-visible data changes go in the next changelog entry.
6. A rate change usually reaches the regions at different times (§5), so check which region a source is describing.
